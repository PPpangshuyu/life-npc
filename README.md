# 日常小人 LifeNPC

**个人生活入帧。**

把自己的照片与日常场景，做成同一个角色主演的复古低多边形短片。这是给 Codex 使用的工作流 skill，包含人物确认、场景与动作设计、局部动画合成、心情气泡和实际视频检查。

## 使用流程

1. **首次建立角色**：上传一张清晰的全身或半身个人照。Codex 生成个人形象预览；你可以要求微调，满意并确认后才进入视频制作。
2. **提供场景**：上传一张或多张场景照片，按顺序为每张写“做什么＋心情如何／思考什么”。如果照片和描述已经一起发送，确认人物后直接继续，不重复索取。
3. **接收视频**：每张场景照片对应一个完整 MP4，按顺序分别交付。后续调用复用已确认角色；需要换人或重新设计时再确认。

例如：

```text
使用 $life-npc。
照片1：撑遮阳伞赶往工位，疲惫困倦，想回床上睡觉。
照片2：在工位敲键盘记录纪要，紧张。
照片3：用紫色网球拍有力击球一次，然后跳起握拳庆祝，很开心。
```

默认竖屏 1080×1920、30 fps，按动作安排时长。画风是清晰分面、粗糙低分辨率纹理、低饱和暖灰色调；保留不同场景的昼夜和灯光。心情用同画风的独立图标气泡，具体想法可用短文字小窗。人物预览会先展示；个人形象和每场景代表帧也保存在本地，需要时可额外交付。

## 在 Codex 使用

下载本仓库后，把整个 `skills/life-npc` 文件夹放进当前项目的 `.agents/skills/`，或者自己的 `~/.agents/skills/`。已有同名 skill 时先选择保留版本，避免意外覆盖。

发布到 GitHub 后，也可以在 Codex 中请求：

```text
请使用 $skill-installer，从这个 GitHub 仓库安装 skills/life-npc：https://github.com/PPpangshuyu/life-npc
```

安装后调用 `$life-npc`。如果列表尚未更新，重启 Codex。仓库同时附带一个单 skill 的 `plugin.json`，便于以后按插件分发；这不代表已经上架或通过插件商店审核。安装和发现方式见 [Codex 官方技能文档](https://learn.chatgpt.com/docs/build-skills)，插件格式见 [官方打包文档](https://developers.openai.com/plugins/build/plugins)。

## 运行条件

- 当前 Codex 环境必须能读取照片，并具备可调用的图像生成与编辑工具。仅安装本仓库不会提供这些能力；缺少时代理会明确指出缺项。
- 本地 Python 3.10+，以及 `skills/life-npc/scripts/requirements.txt` 中的依赖。
- 本地 FFmpeg 和 FFprobe；所选功能需要 H.264 编码 `libx264`，局部补帧需要 `minterpolate`，调色需要 `lut3d`。

可在仓库目录按需要准备独立 Python 环境：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r skills/life-npc/scripts/requirements.txt
.venv/bin/python skills/life-npc/scripts/resolve_runtime.py
```

Windows 使用 `.venv\Scripts\python.exe` 执行对应命令。把 FFmpeg/FFprobe 放入 PATH，或使用 `FFMPEG_PATH` / `FFPROBE_PATH`、脚本的显式参数指定。运行时定位脚本不会自动下载或安装软件。只有用到某一动画方法时才需要其对应素材与配置；可用各脚本的 `--help` 查看契约。

不需要额外安装 Runway 等视频软件。本仓库不附模型权重、图像生成额度或第三方服务账号；模型服务是否收费取决于使用者的实际环境与方案。默认走本地合成，不自动开通付费服务。

## 资料保存

安装包只保存代码和通用约定。默认私人数据目录为当前工作区的 `.life-npc/`，也可在调用时指定固定目录，或设置 `LIFE_NPC_HOME` 以便跨项目复用同一角色。

```text
.life-npc/
  identity/       个人照、候选角色、批准角色和确认记录
  motions/        当前身份的动作缓存
  mood-icons/     本地生成的心情图标
  runs/           场景输入、提示词、关键帧、视频和检查记录
```

工作流在私人目录内创建忽略规则，仓库也忽略这些文件。仓库不包含作者的个人照、角色、场景照片、历史成片和身份动作缓存。照片在生成时会提交给用户当前选择的图像生成工具处理，因此“本地保存”不等于图像生成完全离线。不要把带私人资料的运行目录作为公开示例上传。

## 当前能力与限制

- 使用图像素材与局部／分层动画，角色设定图不是可旋转的真实三维模型。
- 大动作、遮挡变化和自然步行可能需要更多素材；小动作光流也可能产生重影，必须检查实际导出视频，必要时换成明确姿态或增加中间姿态。
- 五分钟是已确认角色、输入完整且可复用动作时的单场景目标，不是首次运行或任意动作的保证。生成排队、用户确认、返工和批量场景都可能增加耗时。
- 当前公开包已做本地脚本检查和合成几何素材测试，尚未完成另一位真实用户从首次照片到成片的端到端试用，也未宣称在所有系统上实测。

## 仓库内容与许可

`skills/life-npc/SKILL.md` 是入口，`references/` 为人物确认和制作细则，`scripts/` 为可重复使用的本地合成工具，`assets/style/` 为通用配色参数。
